01 / programming the device

cores, memory, kernels

A Metalium program coordinates data movement and compute: reader kernels load tiles into circular buffers, compute kernels consume them, and writer kernels store results. These references explain the synchronization and memory layout at each step.

How Tensix cores use local SRAM and networks-on-chip (NoCs). Covers tiles, circular buffers, and synchronization between reader, compute, and writer kernels.

Tensix core and LLKs

Low-level kernels (LLKs): unpack tiles, execute matrix or vector operations, hold results in destination registers, and pack them for storage.

02 / setup

  1. 01
    check PCIe, power, and cooling

    With the system powered off, install the p150a in the dock and connect the specified power cables. Keep the card's airflow unobstructed and follow the card and dock installation manuals.

    prepare the Linux host

    This workstation configuration uses Ubuntu 24.04. Check the vendor's OS and BIOS requirements for your software release before installing.
